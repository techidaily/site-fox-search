Advanced Installer can **digitally sign** all of the following files that it creates: EXE, MSI, MSP (patches) and CAB files. The **EXE, MSI and MSP files** are always signed while the CAB files are only signed if they are not embedded in the MSI.

You also can individually sign each file from your package by enabling this option in the [File Properties Tab](https://tools.techidaily.com/advancedinstaller/products/), [Files and Folders](https://tools.techidaily.com/advancedinstaller/products/) view.
